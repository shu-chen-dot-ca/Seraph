# Papers

On **Workspace → Papers**, choose **Add paper** and give it a PDF or a link. An agent then goes through these steps:

1. **Read**: the whole paper.
2. **Set up**: in a VM, with public data only.
3. **Rebuild**: the method, from the paper alone.
4. **Compare**: its results with the paper's results and with the authors' code.
5. **Check**: every claim, with a command whose output is the proof.
6. **Report**: a **Report** in the Inbox, with Overview, Results, Problems and Files.

Approving the report ends the job, and nothing is sent anywhere. The agent never uses data that needs a credential, and never contacts the authors.
